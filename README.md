In-Memory Warehouse and Stock Management System

A high-performance warehouse management and inventory engine developed in Java for the national programming competition.

Key Features:

Multiple Data Sources: File Loader for local CSV files, Random Generator for large-scale stress testing, and API Integration using Java HttpClient.

In-Memory Indexing and Sorting: Optimized data structures with fast searching and multi-criteria sorting by name, price, or stock level.

Transaction and Undo Engine: Tracks stock movements with a history stack supporting operation rollbacks.

Tech Stack:
Language: Java

Environment: IntelliJ IDEA
